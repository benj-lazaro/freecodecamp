Build A Profile Lookup
----------------------
- In this lab
    - You will build a profile lookup that looks up information about people in a contacts list


- User Stories:
    - You should create a function named "lookUpProfile" that 
        - Takes a name and a property as arguments

    - You should retrieve contact information from the provided "contacts" array

    - If the function receives a contact name and the property exists on the related contact
        - Then the property's value should be returned

    - If the name passed to the function does not match any contacts in the "contacts" array
        - Then the function should return "No such contact"

    - If the property does not exist on a found contact
        - Then the function should return "No such property"
